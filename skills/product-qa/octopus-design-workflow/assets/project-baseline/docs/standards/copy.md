# 标准文案库

> 语义归一、句式规则、术语表请读 [copywriting-normalization.mdc](../../cursor-rules/copywriting-normalization.md)。
> 本文件是**文案速查**——面向特定场景直接抄用，工程侧建议落成 `src/constants/copy.ts` 常量。

## 一、操作反馈

| 场景 | 标准文案 |
|---|---|
| 保存成功 | 保存成功 |
| 提交成功 | 提交成功 |
| 删除成功 | 删除成功 |
| 复制成功 | 复制成功 |
| 导入成功 | 导入成功 |
| 导出成功 | 导出成功 |
| 保存失败 | 暂时无法保存，请稍后重试 |
| 保存失败（含校验） | 暂时无法保存，请检查必填项后重试 |
| 提交失败 | 暂时无法提交，请检查后重试 |
| 删除失败 | 暂时无法删除，请稍后重试 |
| 上传失败 | 上传失败，请检查文件格式后重试 |

## 二、二次确认

| 场景 | 标准文案 |
|---|---|
| 删除确认（通用） | 删除后无法恢复，是否确认继续？ |
| 删除确认（带对象名） | 确认删除「{name}」？删除后无法恢复 |
| 作废确认 | 作废后无法恢复，是否确认继续？ |
| 停用确认 | 停用后相关业务将受影响，是否确认继续？ |
| 取消未保存内容 | 当前内容尚未保存，离开后将丢失，是否确认离开？ |
| 批量操作确认 | 已选中 {n} 条记录，是否确认{action}？ |

## 六、按钮文案

| 场景 | 标准文案 |
|---|---|
| 新建类 | 新增（**不用**"添加""新建"） |
| 确认按钮（单独） | 确定（**不用**"确认"） |
| 确认动作（带对象） | 确认删除 / 确认提交 / 确认作废 |
| 等待提示 | 请稍候（无动作）/ 请稍后重试（有动作） |
| 加载中 | 加载中… / 提交中… / 保存中… |

## 七、用词统一

| 不推荐 | 推荐 | 说明 |
|---|---|---|
| 您 | 你 | 默认产品文案用"你"（正式公文除外） |
| 该订单 / 该记录 | 此订单 / 此记录 | "此"指代当前对象更明确 |
| 帐号 | 账号 | 登录身份 |
| 账号（指钱） | 账户 | 资金、余额、结算 |
| 登陆 | 登录 | 进入系统 |
| 添加 / 新建 | 新增 | 统一基础规范 |
| 完结 | 完成 | 任务、流程、结果 |
| 操作失败 | 暂时无法 {动作}，请稍后重试 | 给出结果 + 下一步 |
| 抱歉，输入有误 | 请检查后重新输入 | 不责怪用户 |

完整术语表详见 [copywriting-normalization.mdc](../../cursor-rules/copywriting-normalization.md)。
