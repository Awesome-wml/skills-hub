# 表单页产品规范

> 工程实现参考：[page-edit.mdc](../../cursor-rules/page-edit.md) / [master-conventions.mdc 八、VabSchemaFormDialog/Drawer 规范](../../cursor-rules/master-conventions.md)

## 1. 适用范围

表单页适用于**新增、编辑、查看、复制新建、审批填写**等场景。核心目标：**降低录入成本、提升填写效率、保证数据质量**。

## 2. 布局

| 场景 | 布局 |
|---|---|
| 简单表单 | 单列布局 |
| 常规业务表单 | 双列布局 |
| 复杂业务表单 | 分组布局 + 分区卡片（`control: 'divider'` 分组标题） |

- 同一表单内**标签宽度统一**。
- 表单组之间垂直间距、单个表单项间距走 token，详见 [design-tokens.md](./design-tokens.md)。
- VabSchemaForm 默认 `defaultColSpan: 8`（一行三列），字段少时改为 12（双列）或 24（单列）。

## 3. 标签与字段

- 标签使用**明确业务名称**，避免口语化或含义模糊。
- 标签长度建议 **2~8 个汉字**。
- **必填项使用红色星号标识**，置于标签前方（`required: true` 自动渲染）。
- 字段宽度按内容档位：

| 档位 | 适用场景 |
|---|---|
| 短字段 | 编码、数量、单位 |
| 中字段 | 名称、分类 |
| 长字段 | 地址短版、备注摘要 |
| 整行（`colSpan: 24`） | 备注、地址、说明、富文本、附件 |

具体宽度由组件库默认值或 design-tokens 中的 input size 控制，**不在业务代码里写死 px**。

## 4. 字段状态

| 状态 | 说明 | 工程实现 |
|---|---|---|
| 默认态 | 可编辑、可输入 | — |
| 只读态 | 可见但不可修改，应与普通输入**明显区分** | `readonly` / 切换到 `el-descriptions` |
| 禁用态 | 置灰，不可点击，表示当前流程不可操作 | `disabled` / `disabledOnEdit: true` |
| 隐藏态 | 不展示且不占用布局空间 | `v-if` / `hideInTable` |

**编码类字段必须 `disabledOnEdit: true`**。

## 5. 校验与默认值

- **必填校验在提交时触发**（提交后高亮未填项）。
- **格式校验在失焦时触发**。
- 错误提示显示在**字段下方**，文案需明确说明原因，参考 [copy.md](./copy.md)。
- 允许设置高频字段默认值：当前用户、当前日期、当前组织、系统预设值。
- **前端计算值不入库**，策略值（税率/运费/折扣）必须由后端 `GET /xxx/form-preferences` 下发——详见 [data-integrity.mdc](../../cursor-rules/data-integrity.md)。

## 6. 按钮与离开提醒

- 标准按钮组合：**保存、保存并提交、提交、取消、返回**。
- 主按钮在前，次按钮在后；表单底部按钮默认**右对齐**。
- 保存、提交、导入等动作触发后**按钮进入 loading 状态**，防止重复点击。
- **未保存内容离开确认**：

  > 当前内容尚未保存，离开后将丢失，是否确认离开？

  详见 [copy.md](./copy.md)。

## 7. 审批态表单

- **已提交审批的单据默认不可编辑**。
- **审批意见、审批动作单独成组**。
- 审批日志与单据内容分区展示（用不同 Section）。
- 审批人仅展示必要可操作字段。

## 8. 容器选型速查

| 场景 | 容器 | 依据 |
|---|---|---|
| 字段 ≤ 12 且无子表格 | `VabSchemaFormDialog` | 弹窗首选 |
| 字段多或含子表格 | `VabSchemaFormDrawer` | 抽屉 |
| 有独立 URL 的新增/编辑页 | 路由页 + `VabSchemaForm` | 少见，多用于超复杂单据 |
| 详情页就地编辑 | `VabDetailPage` + `useDetailPageEdit` | 查看为主、偶尔编辑 |
