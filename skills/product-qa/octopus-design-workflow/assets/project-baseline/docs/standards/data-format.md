# 数据格式规范

> 工程实现建议：把下列 formatter 落成 `src/utils/format.ts` 工具函数，统一调用。

全系统数据展示格式：

| 字段类型 | 标准格式 | 示例 |
|---|---|---|
| 日期 | `YYYY-MM-DD` | `2026-04-15` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` | `2026-04-15 09:30:00` |
| 时间（不含日期） | `HH:mm:ss` | `09:30:00` |
| 月份 | `YYYY-MM` | `2026-04` |
| 金额 | 千分位 + 2 位小数 | `12,345.67` |
| 数量 | 0 ~ 4 位小数，同字段保持统一 | `12,345` / `12,345.5000` |
| 百分比 | 0 ~ 2 位小数 + `%` | `32.5%` |
| 空值 | `--`（全系统统一） | `--` |

## 使用约束

- **空值一律显示 `--`**，禁止显示空字符串、`null`、`undefined`、`N/A`、`无`。
- **金额列必须右对齐 + 等宽数字**：用 `className: 'is-money'`（VabSchemaTable 已内置样式）。
- **同一字段在列表和详情必须使用同一种格式**（比如创建时间都用 `YYYY-MM-DD HH:mm:ss`）。
- **时区**：所有时间由后端统一按用户时区返回，前端不做时区换算。

## 反例

```vue
<!-- ❌ 禁止 -->
<span>{{ row.amount }}</span>                         <!-- 原始数字，未千分位 -->
<span>{{ row.createdAt || '无' }}</span>              <!-- 自定义空值文案 -->
<span>{{ row.rate + '%' }}</span>                     <!-- 没控制小数位 -->

<!-- ✅ 正确 -->
<span>{{ formatMoney(row.amount) }}</span>            <!-- 12,345.67 -->
<span>{{ formatDateTime(row.createdAt) }}</span>      <!-- 空自动 -- -->
<span>{{ formatPercent(row.rate) }}</span>            <!-- 32.50% -->
```
