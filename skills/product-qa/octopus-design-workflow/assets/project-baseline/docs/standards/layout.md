# 整体布局规范

> 所有间距数值见 [design-tokens.md §二、间距](./design-tokens.md)，本文件只描述区块结构与语义。
> 工程实现参考：[page-overview.mdc](https://gitee.com/lengfeng_2/octopus-admin/blob/85467a2ca6b810c0abd5e77ccb41b32eed37338d/.cursor/rules/page-overview.mdc) / [element-size.mdc](../../cursor-rules/element-size.md#二间距系统)

适用端：PC 后台。

## 1. 页面整体结构

后台标准页面由以下区块组成：

- 顶部导航区
- 左侧菜单导航区
- 主内容区
  - 面包屑区
  - 页面标题区
  - 查询/筛选区
  - 操作按钮区
  - 内容展示区
  - 分页区

## 2. 区块语义间距

间距的实际值见 [design-tokens.md](./design-tokens.md)，本表只声明语义对应：

| 区块 | 间距语义 |
|---|---|
| 页面左右内边距 | 页面级内边距 |
| 模块上下间距 | 大区块间距 |
| 卡片内边距 | 卡片内边距 |
| 卡片之间垂直间距 | 大区块间距 |
| 卡片标题与内容区之间 | 大区块间距 |
| 表单 gutter | 表单 gutter |

**禁止硬编码 px**，全部走 token。

## 3. 内容容器

- 查询区、表格区、表单区、详情区**使用独立卡片承载**。
- 卡片**不使用重阴影**，优先采用浅边框或浅背景区分层级。
- 卡片圆角语义参见 [design-tokens.md §四、圆角](./design-tokens.md)。

## 4. 对齐与栅格

- 页面标题、面包屑、卡片内容统一**左对齐**。
- 查询区字段统一按**栅格对齐**，使用 24 栅格体系或等效布局。
- 查询区常用**多列布局**（推荐 4 列，根据屏幕宽度自适应）。
- 表单页常用**双列或三列布局**（VabSchemaForm 默认三列，字段少时压缩）。
- 同类页面保持相同区块顺序、按钮位置和字段对齐方式。

## 5. 滚动与吸顶

- **默认采用整页滚动**；表格数据较多时允许表格区域独立滚动（通过 `auto-height-container` 实现）。
- 页面**不得同时出现多个主要滚动条**，避免操作混乱。
- 长表格场景建议表头吸顶；复杂业务页可支持主操作栏吸顶。
