## 本轮实现与边界

本地 `artifacts/retail-order-prototype-v2` 为独立 LFerp 原型输出，入口继续挂在原本的订单预览 URL。使用真实 Vue/Element Plus 基础组件，不复用旧 LFerp 业务脚本；这是原型展示层，不代表新增或抽取了 Admin 的 VabSchemaTable。Admin 实施仍须复用项目组件和真实 SDK。

样本来自设计画面；9 个设计行通过独立 fixture ID 支持选择，不把重复示例订单号假装成真实记录。设计示例计数不是后台总量。原型内查询仅演示样本过滤，匹配精度、时间范围限制、权限、金额筛选字段仍须按真实系统/接口补齐，不能作为新业务契约。买家账号电话和 ID 未出现在样本时保持缺失，不从收货信息填充。

本轮覆盖列表结构与组件交互。详情仅为选中样本摘要；完整详情、取消/售后/上传流程、清分导出目录和 SDK 映射未完成，业务 UAT 未执行。后续页面不能以旧 LFerp 为补齐来源。

依据 `../prototype-components.md`，订单时间与买家信息共用 `OctoQueryGroup`；行操作共用 `OctoTableActions`。组件规范、共享 Token 与实现先完成独立样例验读，然后页面替换消费处。页面不再维护前缀连接边框或 dropdown 独立间距。查看/更多同为 text/default、32px 高、14px 字号和相同内边距；更多因箭头自然更宽。业务动作及查询模型由页面传入，本次未扩展业务语义。
